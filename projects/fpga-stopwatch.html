FPGA-Based Programmable Stopwatch/Timer

Verilog, Basys3 (Artix-7) · April 2026

Overview

I built a four-mode stopwatch/timer entirely in structural RTL and brought it through synthesis, place, and route to a timing-closed bitstream on a Basys3 board. The design counts seconds and centiseconds up or down, and can either start from zero/roll over from 99.99, or start from a value dialed in on the board's switches — so it doubles as both a stopwatch and a countdown timer without changing hardware.

  • Six-module RTL design: clock divider, debounced button-pulse generator, a Moore FSM controller, a BCD up/down time counter, a 4-digit multiplexed display driver, and a 7-segment decoder
  • Mode select and settable start value driven live off the board's 10 slide switches, decoded combinationally by the controller
  • Verified in Vivado through synthesis and full implementation (place & route) on the Basys3 board, with all timing constraints met

Architecture

main_stopwatch is the top level; everything else is a leaf module it wires together:

  • clockdiv — divides the 100 MHz board clock down to a 10 ms tick (counts to 999,999) that paces the time counter
  • button_pul — edge-detects the raw start/reset button inputs into single-cycle pulses, instantiated once per button, so a held button doesn't repeat-trigger the FSM
  • cont — the controller: a 3-state Moore FSM (done → continue → stop) that decodes the 2-bit mode switch into a count direction and load value, and gates the counter's enable/load lines off the start/reset pulses and the counter's own start/max flags
  • time_counter — the BCD counter itself: two seconds digits and two centisecond digits, counting up or down on each 10 ms tick, with synchronous load from the controller's decoded start value
  • main_stopwatch (display mux) — a free-running 16-bit refresh counter selects which of the 4 digits is active, driving the anode lines and routing that digit's BCD value to the decoder fast enough that all 4 digits appear lit simultaneously
  • val_to_7seg — combinational BCD-to-seven-segment decoder

The four modes are selected on sw[9:8]: count up from zero, count down from 99.99, count up from a switch-set value, and count down from a switch-set value — with the start value itself dialed in on sw[7:4] (seconds tens) and sw[3:0] (seconds ones).

Controller FSM

This is the piece that ties the rest of the design together — it decodes the mode switches into a load value and count direction, then arbitrates start/stop transitions off the debounced button pulses and the counter's own boundary flags (start when it hits zero, max when it hits 99.99): 

// next-state logic
always @(*) begin
    next_state = state;

    case(state)
        done: begin
            if (start_pulse)
                next_state = continue;
        end

        continue: begin
            if (reset_pulse)
                next_state = done;
            else if (start_pulse)
                next_state = stop;
            else if ((c_up == 1'b0 && start) || (c_up == 1'b1 && max))
                next_state = stop;
        end

        stop: begin
            if (reset_pulse)
                next_state = done;
            else if (start_pulse)
                next_state = continue;
        end
    endcase
end

Full source for all six modules and the pin constraints file is on GitHub. The design was carried through synthesis and full place & route in Vivado, with all timing constraints met at the board's 100 MHz clock and zero failing paths.
